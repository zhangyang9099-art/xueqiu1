## 三、分析指令

这是最关键的分析层。需要逐线程、逐用户检查操纵信号：

### 检查维度

1. **账号可疑度**
   - 默认昵称（如"用户xxxx"）+ 默认头像 = 高度可疑
   - 低发言量（status_count < 10）突然大量评论 = 新号入场
   - 粉丝为0或极少 = 可能是批量注册的小号

2. **集中爆发**
   - 短时间（1小时内）大量新用户同向发言 = 协调行动
   - 相似的发言模式/用词 = 模板化水军

3. **言论一致性**
   - 多个可疑账号在同一帖子发表相似观点 = 协同引导
   - 与主流观点高度一致但论据雷同 = 可能是安排好的

4. **股价配合**
   - 舆论方向与股价走势高度同步 = 可能有提前安排
   - 利好消息伴随大量"看好"评论后股价下跌 = 典型出货信号

5. **跨帖协同**
   - 同一用户/账号群在多个帖子发表类似观点 = 有组织行动
